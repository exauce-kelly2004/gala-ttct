# DESIGN.md --- TTCT SOIRÉE DE GALA 2026

## Direction artistique --- Tradition contemporaine, héritage & prestige

> **Statut : document de référence visuelle**
>
> Ce document remplace les directions artistiques précédentes. La
> nouvelle identité du site TTCT doit s'appuyer sur la **force visuelle
> de la référence fournie par le client** : couleurs chaudes, motifs
> géométriques inspirés des arts et textiles africains, composition
> graphique affirmée, illustration éditoriale, répétition de motifs et
> sensation d'héritage culturel.
>
> **Important :** la référence est une source d'inspiration pour son
> langage graphique. Il ne faut pas recopier ses personnages, ses
> textes, ses illustrations ou sa composition. L'objectif est de
> transposer son **énergie visuelle et son vocabulaire traditionnel** à
> l'univers d'une soirée de gala TTCT.

------------------------------------------------------------------------

# 1. VISION CRÉATIVE

## Concept central

Le site doit exprimer :

**TRADITION → HÉRITAGE → FIERTÉ → TRANSMISSION → CÉLÉBRATION → GALA**

Le mot-clé principal est :

# TRADITION

Mais il ne s'agit pas de créer un site folklorique ou ancien.

Le résultat recherché est une **tradition contemporaine** :

-   racines africaines ;
-   motifs patrimoniaux ;
-   couleurs terre, safran et orange ;
-   élégance événementielle ;
-   composition éditoriale ;
-   détails graphiques riches ;
-   expérience numérique moderne ;
-   parcours d'achat simple et efficace.

Le site doit donner l'impression d'une identité conçue par une vraie
direction artistique, pas d'un template généré par IA.

------------------------------------------------------------------------

# 2. RÉFÉRENCE VISUELLE PRINCIPALE

La référence fournie présente plusieurs caractéristiques à reprendre
dans l'esprit :

-   fonds orange/safran très présents ;
-   crème/beige chaud ;
-   brun très foncé presque noir ;
-   motifs géométriques répétés ;
-   bandes décoratives ;
-   formes concentriques ;
-   symboles graphiques ;
-   illustrations à l'encre ;
-   grandes zones de couleur pleine ;
-   alternance de blocs très graphiques ;
-   typographie de caractère ;
-   contraste très fort ;
-   composition presque éditoriale / affiche ;
-   sensation artisanale et culturelle ;
-   répétition volontaire des motifs ;
-   langage visuel cohérent sur toute la page.

### Ce qui doit être conservé

**La force.**

**Le rythme.**

**Les couleurs.**

**Les motifs.**

**La matérialité.**

**L'identité culturelle.**

### Ce qui ne doit PAS être copié

-   les personnages présents dans la référence ;
-   les illustrations exactes ;
-   les textes ;
-   le logo ;
-   les compositions exactes ;
-   les éléments graphiques appartenant à l'auteur de la référence ;
-   une reproduction pixel par pixel.

------------------------------------------------------------------------

# 3. POSITIONNEMENT VISUEL TTCT

Le site doit être perçu comme :

> **Un gala contemporain enraciné dans la tradition.**

Il ne doit pas ressembler à :

-   un site SaaS ;
-   une landing page startup ;
-   un site fintech ;
-   un site de mariage générique ;
-   un template d'agence ;
-   un site africain générique utilisant simplement du orange ;
-   un site "festival" rempli de gradients ;
-   une interface entièrement composée de cartes.

Le design doit avoir une **signature**.

------------------------------------------------------------------------

# 4. PALETTE CHROMATIQUE

La palette est volontairement chaude.

## Couleurs principales

  Nom                  Hex         Usage
  -------------------- ----------- -----------------------------------
  Saffron              `#FBAA01`   grands fonds, sections majeures
  Orange terre cuite   `#FB821A`   accents, transitions, blocs
  Crème chaud          `#F7D7A6`   fonds clairs, respirations
  Brun profond         `#3F0B07`   texte principal sombre, contraste
  Terre brune          `#8C4A1C`   motifs, illustrations, détails
  Or chaud             `#D0862E`   accents premium
  Beige doré           `#EFC883`   fonds secondaires et nuances

### Règle

Ne pas utiliser toute la palette à chaque section.

Une section peut fonctionner avec :

**Saffron + Brun**

ou :

**Crème + Brun + Orange**

ou :

**Orange + Crème + Brun**

Le contraste doit être contrôlé.

------------------------------------------------------------------------

# 5. INTERDICTIONS COLORIMÉTRIQUES

Ne pas introduire :

-   bleu électrique ;
-   violet ;
-   cyan ;
-   vert néon ;
-   rose flashy ;
-   gradients arc-en-ciel ;
-   glassmorphism bleu/violet ;
-   fonds noirs froids dominants ;
-   palette "tech".

Un brun très sombre peut être utilisé comme équivalent du noir.

------------------------------------------------------------------------

# 6. MOTIFS TRADITIONNELS

Les motifs sont un élément STRUCTURANT de l'identité.

Ils ne doivent pas être ajoutés comme décoration aléatoire.

## Familles de motifs

Créer un système cohérent basé sur :

-   losanges ;
-   entrelacs géométriques ;
-   zigzags ;
-   lignes répétitives ;
-   cercles concentriques ;
-   symboles abstraits ;
-   bordures inspirées du textile ;
-   formes géométriques symétriques.

## Utilisation

Les motifs peuvent apparaître :

-   dans le hero ;
-   dans les séparateurs ;
-   en bordure de section ;
-   derrière certains titres ;
-   sur les billets ;
-   dans le footer ;
-   dans les états de confirmation ;
-   dans les éléments décoratifs du checkout ;
-   dans le ticket PDF.

### Règle importante

Les motifs doivent être **visuellement forts mais hiérarchiquement
secondaires** au contenu.

Ils ne doivent jamais empêcher la lecture.

------------------------------------------------------------------------

# 7. SYSTÈME DE BORDURES

La référence utilise fortement les bandes et bordures.

Le site peut reprendre ce principe avec :

-   bandes horizontales ;
-   bordures répétitives ;
-   lignes doubles ;
-   petits motifs géométriques ;
-   séparateurs décoratifs ;
-   cadres partiels.

Éviter de mettre un cadre autour de chaque élément.

Le cadre est un outil de composition, pas une décoration automatique.

------------------------------------------------------------------------

# 8. TYPOGRAPHIE --- PRINCIPE

## IMPORTANT

La typographie définit une grande partie de l'identité.

**Claude Code ne doit pas choisir et installer définitivement les
polices sans validation préalable.**

Avant toute implémentation typographique, Claude doit :

1.  proposer plusieurs combinaisons ;
2.  montrer visuellement les combinaisons ;
3.  expliquer le rôle de chaque police ;
4.  vérifier la licence / disponibilité web ;
5.  demander validation ;
6.  attendre la validation ;
7.  seulement ensuite installer et intégrer les polices.

------------------------------------------------------------------------

# 9. DIRECTION TYPOGRAPHIQUE RECHERCHÉE

La typographie doit avoir :

-   du caractère ;
-   une personnalité culturelle ou éditoriale ;
-   une bonne présence dans les grands titres ;
-   une excellente lisibilité dans les textes ;
-   une hiérarchie forte.

### Architecture souhaitée

**Police DISPLAY / TITRES**

Pour :

-   GALA ;
-   grands titres ;
-   chiffres ;
-   titres de sections ;
-   mots-clés.

Elle peut être expressive, condensée, légèrement rétro ou inspirée de
l'affiche.

**Police TEXT / UI**

Pour :

-   navigation ;
-   paragraphes ;
-   boutons ;
-   formulaire ;
-   checkout ;
-   dashboard ;
-   scanner ;
-   messages d'erreur ;
-   emails.

Elle doit rester extrêmement lisible.

### Accent scriptuel

Un script peut éventuellement être proposé pour un mot court comme :

**Soirée**

mais seulement si cela reste élégant et lisible.

------------------------------------------------------------------------

# 10. VALIDATION TYPOGRAPHIQUE OBLIGATOIRE

Claude doit présenter au minimum **3 propositions de couples
typographiques** avant implémentation.

Pour chaque proposition :

-   nom des polices ;
-   aperçu H1 ;
-   aperçu H2 ;
-   aperçu paragraphe ;
-   aperçu bouton ;
-   aperçu prix ;
-   justification ;
-   licence/source ;
-   avantages ;
-   risques ;
-   compatibilité mobile.

Aucune police ne doit être installée définitivement avant validation
humaine.

------------------------------------------------------------------------

# 11. IMAGERIE --- PRINCIPE

Les images doivent renforcer le concept :

**héritage + élégance + célébration + Afrique contemporaine + gala**

Mais le site ne doit pas devenir une banque d'images génériques
"Afrique".

## Images à privilégier

-   portraits éditoriaux ;
-   détails textiles ;
-   matières artisanales ;
-   bijoux et accessoires ;
-   architecture et décoration ;
-   gestes et savoir-faire ;
-   motifs traditionnels ;
-   matières naturelles ;
-   scènes de célébration élégantes ;
-   détails de table / décoration ;
-   lumière chaude ;
-   silhouettes habillées ;
-   éléments liés au gala.

## À éviter

-   photos stock clichées ;
-   images surchargées ;
-   photos artificielles ;
-   visuels IA reconnaissables ;
-   clichés touristiques ;
-   images sans rapport avec le gala ;
-   répétition de la même photo.

------------------------------------------------------------------------

# 12. VALIDATION DES IMAGES OBLIGATOIRE

Claude ne doit PAS télécharger et intégrer immédiatement des images au
projet.

Avant implémentation :

1.  identifier les besoins image par image ;
2.  proposer plusieurs candidats ;
3.  fournir les sources / liens ;
4.  préciser la licence ou les conditions d'utilisation ;
5.  montrer où chaque image serait utilisée ;
6.  proposer une alternative si l'image n'est pas validée ;
7.  attendre la validation humaine.

### Si aucune photo professionnelle n'est disponible

Claude doit utiliser temporairement :

-   des placeholders élégants ;
-   des compositions graphiques ;
-   des textures ;
-   des motifs ;
-   des cadres réservés aux futures photos.

Il ne doit pas inventer une fausse photographie officielle de
l'événement et la présenter comme réelle.

------------------------------------------------------------------------

# 13. DIRECTION PHOTOGRAPHIQUE

Les images finales doivent privilégier :

-   lumière chaude ;
-   contraste maîtrisé ;
-   tons terre ;
-   détails de matière ;
-   profondeur ;
-   cadrages éditoriaux ;
-   présence humaine naturelle ;
-   vêtements élégants ;
-   ambiance de célébration ;
-   authenticité.

Le traitement photo peut reprendre légèrement :

-   orange ;
-   safran ;
-   crème ;
-   brun ;
-   doré.

Sans transformer toutes les images en filtre orange.

------------------------------------------------------------------------

# 14. HERO

Le hero doit immédiatement annoncer :

**TTCT --- SOIRÉE DE GALA**

Le hero doit être spectaculaire mais culturel.

## Structure possible

-   texture / motif traditionnel en arrière-plan ;
-   grande zone safran/orange ;
-   logo TTCT ;
-   petit label "Soirée de Gala" ;
-   titre monumental ;
-   date ;
-   courte promesse ;
-   compte à rebours ;
-   CTA réservation ;
-   motif décoratif latéral ;
-   détail graphique inspiré du textile.

### CTA principal

**RÉSERVER MON PASS**

Le CTA doit être immédiatement visible.

------------------------------------------------------------------------

# 15. COMPOSITION DU HERO

Éviter un hero SaaS :

> image à gauche + texte à droite + bouton bleu.

Préférer une composition éditoriale :

-   superposition ;
-   bandes ;
-   typographie monumentale ;
-   motifs ;
-   blocs de couleur ;
-   asymétrie contrôlée ;
-   grandes surfaces ;
-   détails décoratifs.

Le hero doit ressembler davantage à une **affiche culturelle digitale
haut de gamme** qu'à une landing page logicielle.

------------------------------------------------------------------------

# 16. NAVIGATION

La navigation doit rester simple.

Structure indicative :

-   Accueil
-   Le Gala
-   Programme
-   Pass
-   Informations
-   FAQ

CTA :

**RÉSERVER**

La navigation peut utiliser :

-   fond transparent au départ ;
-   fond brun/sombre ou crème au scroll ;
-   petite bordure décorative ;
-   motif discret.

La lisibilité reste prioritaire.

------------------------------------------------------------------------

# 17. STRUCTURE DE LA PAGE

## 1 --- HERO

Identité + événement + CTA.

## 2 --- INTRODUCTION

Pourquoi cette soirée existe.

## 3 --- L'HÉRITAGE

Section éditoriale expliquant le lien avec la tradition et la mission du
gala.

## 4 --- EXPÉRIENCE DU GALA

Ce que vivra le participant.

## 5 --- PROGRAMME

Timeline / narration éditoriale.

## 6 --- PASS

Présentation des formules.

## 7 --- INFORMATIONS PRATIQUES

Date, lieu, horaires, dress code, contacts.

## 8 --- FAQ

Questions essentielles.

## 9 --- CTA FINAL

Dernière invitation à réserver.

## 10 --- FOOTER

Logo + navigation + informations + motifs.

------------------------------------------------------------------------

# 18. SECTION PASS / TICKETS

La vente reste la priorité business.

La direction artistique ne doit jamais compliquer l'achat.

Chaque pass doit afficher clairement :

-   nom ;
-   prix ;
-   nombre de personnes ;
-   avantages ;
-   disponibilité si applicable ;
-   bouton d'achat.

Les noms et prix doivent venir des données métier validées.

**Ne jamais inventer ou modifier une formule commerciale.**

------------------------------------------------------------------------

# 19. DESIGN DES BILLETS

Le billet numérique doit prolonger l'identité du site.

Il peut reprendre :

-   fond crème ;
-   brun profond ;
-   orange/safran ;
-   motifs géométriques ;
-   bordures inspirées du textile ;
-   logo TTCT ;
-   typographie validée ;
-   QR code.

Le billet doit néanmoins rester parfaitement lisible et imprimable.

------------------------------------------------------------------------

# 20. CHECKOUT

Le checkout est plus sobre.

Priorités :

1.  compréhension ;
2.  confiance ;
3.  vitesse ;
4.  absence d'ambiguïté ;
5.  paiement ;
6.  confirmation.

L'identité traditionnelle peut apparaître dans :

-   l'en-tête ;
-   les séparateurs ;
-   le résumé ;
-   les micro-détails.

Elle ne doit pas transformer le checkout en affiche.

------------------------------------------------------------------------

# 21. CONFIRMATION

Après paiement :

**RÉSERVATION CONFIRMÉE**

Afficher :

-   référence ;
-   type de pass ;
-   quantité ;
-   informations principales ;
-   statut du paiement ;
-   bouton de téléchargement ;
-   indication d'envoi par email ;
-   QR code / billet selon le flux.

------------------------------------------------------------------------

# 22. DASHBOARD ORGANISATEUR

Le dashboard ne doit pas être décoratif.

Il doit privilégier :

-   lisibilité ;
-   tableaux ;
-   chiffres ;
-   recherche ;
-   filtres ;
-   statuts ;
-   actions.

La direction artistique peut être présente à travers :

-   palette ;
-   typographie ;
-   petites bordures ;
-   motifs très discrets.

------------------------------------------------------------------------

# 23. SCANNER STAFF

Le scanner doit être extrêmement fonctionnel.

Interface :

-   caméra ;
-   cadre de scan ;
-   état en attente ;
-   billet valide ;
-   billet invalide ;
-   billet déjà utilisé ;
-   détails du billet.

Ne jamais dépendre uniquement de la couleur.

Ajouter un message explicite :

**BILLET VALIDE**

ou

**BILLET DÉJÀ UTILISÉ**

------------------------------------------------------------------------

# 24. ANIMATION

Les animations doivent être inspirées du mouvement graphique.

Privilégier :

-   reveal de motifs ;
-   apparition progressive ;
-   déplacement très léger de textures ;
-   transition de bandes ;
-   parallax discret ;
-   micro-animation des bordures ;
-   hover typographique.

Éviter :

-   animations permanentes ;
-   effets 3D gadgets ;
-   particules ;
-   néons ;
-   rotation excessive ;
-   effets "gaming".

------------------------------------------------------------------------

# 25. MOTIFS ANIMÉS

Les motifs peuvent légèrement bouger au chargement ou au scroll.

Exemple :

-   une bordure se révèle ;
-   un motif apparaît progressivement ;
-   une ligne se dessine ;
-   une texture se déplace de quelques pixels.

L'animation doit donner l'impression que le design est vivant, pas que
la page est une démo technique.

------------------------------------------------------------------------

# 26. RESPONSIVE

Mobile-first.

Sur mobile :

-   motifs simplifiés ;
-   titres toujours forts ;
-   CTA accessible ;
-   texte lisible ;
-   images recadrées intelligemment ;
-   aucune décoration ne doit casser le contenu ;
-   checkout extrêmement clair.

Le mobile doit conserver l'identité sans simplement réduire le desktop.

------------------------------------------------------------------------

# 27. ACCESSIBILITÉ

Respecter :

-   contraste ;
-   navigation clavier ;
-   focus visible ;
-   labels ;
-   messages d'erreur ;
-   taille de texte ;
-   zones tactiles ;
-   alt text ;
-   absence de dépendance à la couleur seule.

La tradition ne doit jamais sacrifier l'accessibilité.

------------------------------------------------------------------------

# 28. PERFORMANCE

Les motifs et images peuvent être nombreux.

Donc :

-   SVG optimisés pour les motifs ;
-   WebP/AVIF pour les photos ;
-   `next/image` ;
-   lazy loading ;
-   chargement différé des images secondaires ;
-   éviter les vidéos lourdes en arrière-plan ;
-   éviter les centaines d'éléments DOM décoratifs.

------------------------------------------------------------------------

# 29. SYSTÈME DE DESIGN

## Radius

Privilégier :

-   angles droits ;
-   petits rayons ;
-   formes géométriques.

Éviter les grosses cartes arrondies de type SaaS.

## Ombres

Ombres légères et chaudes.

Pas de grosses ombres noires.

## Bordures

1px principalement.

Certaines bordures décoratives peuvent être plus riches.

## Espacement

Utiliser une échelle cohérente :

`4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 80 / 96 / 128`

------------------------------------------------------------------------

# 30. RÈGLE "PAS DE DESIGN IA GÉNÉRIQUE"

Le site doit éviter les signes classiques d'une interface générée
automatiquement :

-   trop de cartes ;
-   mêmes blocs répétés ;
-   gradients aléatoires ;
-   énormes textes sans composition ;
-   boutons pill partout ;
-   glassmorphism ;
-   icônes génériques ;
-   illustrations 3D génériques ;
-   blobs ;
-   couleurs sans logique ;
-   sections identiques.

La direction artistique doit être reconnaissable même sans le logo.

------------------------------------------------------------------------

# 31. RÈGLE "TRADITION CONTEMPORAINE"

Le site doit répondre simultanément à deux exigences :

### TRADITION

-   motifs ;
-   couleurs ;
-   texture ;
-   symboles ;
-   héritage ;
-   composition graphique.

### CONTEMPORAIN

-   responsive ;
-   UX claire ;
-   typographie maîtrisée ;
-   animations discrètes ;
-   checkout rapide ;
-   accessibilité ;
-   performance.

Si un élément est très traditionnel mais nuit à l'UX, il doit être
simplifié.

------------------------------------------------------------------------
